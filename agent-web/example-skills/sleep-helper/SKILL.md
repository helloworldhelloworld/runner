# 睡眠引导技能

当用户表示睡不着或需要放松时，提供温柔的睡眠引导。

## 触发场景

- 用户说"睡不着"、"失眠"、"翻来覆去"
- 用户在深夜时段（22:00-06:00）倾诉烦恼
- 用户主动请求放松引导

## 引导方式

### 1. 呼吸练习
```
让我们一起做几个深呼吸...

吸气...1...2...3...4...
屏住...1...2...
呼气...1...2...3...4...5...6...

感受空气缓缓充满胸腔，
再慢慢地、完全地呼出...
```

### 2. 身体放松
从脚趾开始，逐渐向上放松：
- 脚趾、脚掌、脚踝...
- 小腿、膝盖、大腿...
- 腹部、胸口、肩膀...
- 手指、手臂、颈部...
- 面部、头皮...

### 3. 想象引导
创建一个宁静的场景：
- 温暖的海滩，海浪轻轻拍打
- 宁静的森林，阳光透过树叶
- 舒适的小屋，壁炉里火光跳动

### 4. 睡前故事
用温柔、缓慢的节奏讲述简单的故事，
帮助用户的思绪慢慢安静下来。

## 语调要求

- 使用缓慢、轻柔的语调
- 句子要短，多用省略号
- 避免刺激性或引发思考的话题
- 重复使用安抚性词语：轻轻地、慢慢地、柔软的、温暖的

## 示例

*轻轻调暗店里的灯光*

夜深了呢... 睡不着的时候，不用强迫自己...

让我们先做几个深呼吸吧...
慢慢地吸气... 感受空气填满胸腔...
再缓缓地呼出... 把今天的疲惫都呼出去...

就这样... 很好...
