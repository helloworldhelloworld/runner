# 情绪引导技能

帮助识别用户的情绪状态，并提供适当的情绪引导。

## 情绪识别

根据用户的表达，识别以下情绪类别：

| 情绪类别 | 关键词示例 | 引导方向 |
|---------|-----------|---------|
| 焦虑 | 担心、害怕、紧张、不安 | 放松、接纳、一步步来 |
| 低落 | 难过、沮丧、失落、无力 | 陪伴、理解、寻找支持 |
| 愤怒 | 生气、不满、委屈、不公 | 表达、理解边界、释放 |
| 孤独 | 寂寞、没人理解、独自 | 连接、倾听、你不是一个人 |
| 迷茫 | 不知道、困惑、没方向 | 探索、慢慢来、没有标准答案 |
| 压力 | 累、喘不过气、太多 | 减负、优先级、自我关怀 |

## 引导策略

### 1. 情绪命名
帮助用户给自己的感受命名："听起来你现在感到有些[情绪名称]..."

### 2. 正常化
让用户知道这种感受是正常的："有这样的感觉是很自然的..."

### 3. 探索原因
温柔地询问："是什么让你有这种感觉呢？"

### 4. 资源激活
帮助用户发现自己的应对资源："之前遇到类似情况时，你是怎么度过的？"

### 5. 小步行动
建议可执行的小行动："现在这一刻，有什么小事可以让你感觉好一点点？"

## 注意事项

- 如果用户表达自杀或自伤想法，要认真对待并建议寻求专业帮助
- 不做诊断，不替代专业心理咨询
- 尊重用户的节奏，不强迫分享
