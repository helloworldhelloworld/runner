## 一、外部参照物最新要点

### 1.1 Claude Code 源码泄露 — 深度架构剖析（2026.4 最新分析）

前次分析聚焦设计点映射，本次补充社区深度拆解后的关键细节：

| 设计点 | 新增细节 | runner 差距 |
|---|---|---|
| **五阶段上下文管线** | (1) Tool Result Budget: 每条消息 size 预算 → (2) Snip: 清空旧 tool_result 保留消息骨架 → (3) Micro: 就地 cache_edits → (4) Context Collapse: 模型端压缩 → (5) Auto: 预留 13K buffer, 生成 ≤20K 摘要, **3 次失败熔断** | runner 0 个阶段；长会话直接 400 |
| **五级权限模型** | default / acceptEdits / plan / bypassPermissions / auto；每个 tool call 过 **五步审批**: tool.checkPermissions() → settings allowlist/denylist → sandbox policy → active permission mode → hook overrides | runner 只有 `isAutoExecute()` 布尔值，无分级无审批链 |
| **Full Compact 再注入** | 压缩后重新注入：最近访问文件 (≤5K/file)、活跃 plan、相关 skill schema；工作预算重置到 50K tokens | runner 无 compaction，自然也无再注入 |
| **autoDream 记忆巩固** | Fork 子 agent + 限制 tool allowlist → 去重/合并/消除矛盾 → 写回记忆 | runner MemoryProvider 只追加，不巩固 |
| **PreCompact Hook** | 提供 `trigger` 字段（manual/automatic），允许在压缩前归档完整上下文 | runner 无 compaction hook |
| **Anti-distillation** | `fake_tools` 注入 decoy 工具定义到 system prompt，防蒸馏 | 安全考量参考，非直接需求 |

### 1.2 OpenClaw 2026.4 — 最新架构演进

| 特性 | 描述 | runner 差距 |
|---|---|---|
| **Plugin SDK 28 Hooks** | 覆盖：model resolution / agent lifecycle / message flow / tool execution / subagent coordination / gateway lifecycle。区分 skills (文本指令) vs plugins (代码模块 + 生命周期 hooks) | runner 的 `AgentObserver` 仅 7 个事件，无 PreToolUse/PostToolUse 拦截；无 plugin SDK 概念 |
| **七阶段 Agentic Loop** | normalize → route → assemble context → infer → ReAct → load skills → persist memory | runner 的 AgentLoop 无显式 normalize/route 阶段 |
| **ACP (Agent Communication Protocol)** | 默认启用的 agent 间通信协议，orchestrator 与 agent runtime 通过 ACP 解耦 | runner 无 agent 间通信机制 |
| **Multi-Agent Orchestrator v4.0** | Supervisor pattern：coordinator 按 agent declared capabilities 路由任务 | runner 完全没有 multi-agent |
| **agent:bootstrap Hook** | 系统 prompt 定稿前注入自定义 bootstrap 上下文 | runner 的 `PromptSection` 部分覆盖，但无 hook 机制触发 |
| **tool_result_persist Hook** | 工具结果写入 session 前的同步变换钩子 | runner 无等效机制 |
| **20+ Channel Adapters** | WhatsApp / Telegram / Slack / Discord / Feishu / WeChat / Matrix 等统一消息抽象 | runner 仅 HTTP REST + WebSocket |
| **ClawHub 技能市场** | 13,729+ 社区技能，可发现/安装/更新 | runner 技能硬编码，无注册/市场 |
