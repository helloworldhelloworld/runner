# ADR-027：同一评测下的候选比较

- 日期：2026-09-07
- 状态：Implemented（CLI 验收通过；完整系统样本待刷新）
- 前置：ADR-021、023

受控改进闭环增加 `compare`：完整核验两个已经执行的候选包，再按相同的评测摘要与
测试身份比较结果。未执行、被修改、验证器版本不一致或评测内容不同的包不得形成
改善结论；源码改动可以包含提示、工具、路由、存储及执行器，不限于 Skill。

比较产物保存两个候选/报告摘要、共同评测摘要、各用例前后状态、回归/修复/缺失用例、
原始反馈与证据引用。用例集合改变时标记不可比较，不能把删除失败用例算作改善。
无新增失败仅称作这套受控验收未观察到回归，不外推为模型质量或线上体验提升。
报告在新目录生成，保留两个原包；只生成分析交接，不执行部署或发布。

命令行验收先验证实际文件/候选/报告之间的内容绑定、准入拒绝和具体用例的分类。
保存报告 fixture 只验证比较器，不冒充真实 Maven 或模型执行结果。最终系统示例仍须
通过冻结副本执行后才能进入比较。

证据篡改及禁止覆盖输入。CLI fixture 不作为实际系统改进证据。
