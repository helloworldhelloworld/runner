# 解忧杂货铺 - 设计文档 🎨

## 设计理念

### 核心价值

**"温暖、简洁、治愈"**

解忧杂货铺不仅是一个聊天应用，更是一个心灵的栖息地。设计的每一个细节都在传递温暖和关怀。

### 设计灵感

1. **东野圭吾的《解忧杂货店》**
   - 温暖的叙事风格
   - 倾听与陪伴的主题
   - 复古而温馨的氛围

2. **苹果的设计语言**
   - 极简主义
   - 优雅的动画
   - 直觉的交互

3. **日式杂货店美学**
   - 柔和的灯光（灯笼图标 🏮）
   - 木质的温暖感
   - 细腻的情感表达

## 视觉设计

### 配色方案

#### 主色调

```
背景色: #FFFFFF (纯白)
- 营造干净、宁静的氛围
- 类似空白的纸张，等待书写故事
```

#### 文本颜色

```
主文本: #1D1D1F (深灰黑)
- 清晰易读
- 符合苹果设计规范
- 不会过于刺眼

次文本: #86868B (中灰)
- 用于辅助信息
- 提供视觉层次
- 柔和不突兀
```

#### 强调色

```
主题色: #F4D9C6 (温暖杏色)
- 灵感来自灯笼的暖光
- 营造温馨的氛围
- 象征希望和治愈

辅助色: #FFF5ED (极浅杏色)
- 主题色的浅色版本
- 用于背景和高亮
```

#### 功能色

```
用户消息: #007AFF (iOS 蓝)
- 系统标准色
- 表示发送方向
- 现代感强

助手消息: #F2F2F7 (浅灰)
- 柔和的背景
- 易于区分
- 不抢夺注意力

分割线: #E5E5EA (极浅灰)
- 若隐若现
- 分隔而不割裂
```

### 图标设计

#### 灯笼图标 🏮

**含义**:
- **传统**: 代表杂货店的复古氛围
- **温暖**: 象征心灵的光明
- **引导**: 在黑暗中指引方向
- **陪伴**: 静静守候的存在

**使用场景**:
- 助手消息头像
- 空状态展示
- 启动画面（未来）

### 字体规范

#### 字体层级

```
1. 页面标题
   - 大小: 20pt
   - 粗细: Semi-bold (600)
   - 用途: "解忧杂货铺"

2. 页面副标题
   - 大小: 13pt
   - 粗细: Regular (400)
   - 用途: "倾听你的心声"

3. 消息正文
   - 大小: 16pt
   - 粗细: Regular (400)
   - 用途: 聊天消息内容

4. 空状态文案
   - 标题: 28pt / Semi-bold
   - 副标题: 15pt / Regular
   - 用途: 首屏引导

5. 辅助文字
   - 大小: 14pt
   - 粗细: Regular (400)
   - 用途: 时间戳、提示信息
```

#### 字体选择

- **中文**: 系统默认字体（鸿蒙字体）
- **英文/数字**: SF Pro（系统自带）
- **Emoji**: 系统 Emoji 字体

### 间距系统

#### 8pt 栅格系统

```
基础单位: 8pt

常用间距:
- 4pt:  极小间距（图标内边距）
- 8pt:  小间距（组件内元素）
- 12pt: 标准间距（组件间）
- 16pt: 大间距（页面边距）
- 20pt: 特大间距（区块间）
- 32pt: 超大间距（空状态）
```

#### 具体应用

```
页面边距: 16pt
消息气泡内边距: 12pt 16pt
输入框高度: 44pt (符合点击热区标准)
发送按钮尺寸: 44pt × 44pt
消息气泡圆角: 20pt
按钮圆角: 22pt (完全圆形)
```

### 圆角规范

```
小圆角: 8pt  (卡片边缘)
中圆角: 12pt (输入框)
大圆角: 20pt (消息气泡)
完全圆角: 50% (圆形按钮)
```

## 交互设计

### 核心交互流程

#### 1. 启动体验

```
应用启动
  ↓
显示空状态
  ├─ 灯笼图标
  ├─ 应用名称
  └─ 欢迎文案
  ↓
后台检查连接
  ↓
显示欢迎消息
```

#### 2. 发送消息流程

```
用户输入文字
  ↓
发送按钮激活（蓝色）
  ↓
点击发送 / 按下回车
  ↓
用户消息立即显示
  ↓
输入框清空
  ↓
显示加载提示
  ↓
接收助手回复
  ↓
移除加载提示
  ↓
显示助手消息
  ↓
自动滚动到底部
```

### 动画效果

#### 消息出现动画

```typescript
// 淡入 + 微弹跳
animation: {
  duration: 300ms
  curve: spring
  opacity: 0 → 1
  translateY: 10px → 0
}
```

#### 按钮状态切换

```typescript
// 颜色平滑过渡
transition: {
  duration: 200ms
  property: backgroundColor
  timing: ease-in-out
}

// 禁用: #C7C7CC (灰色)
// 启用: #007AFF (蓝色)
```

#### 滚动效果

```typescript
// 弹性滚动
edgeEffect: EdgeEffect.Spring

// 自动滚动到底部
scrollEdge(Edge.Bottom)
duration: 300ms
```

## 情感化设计

### 文案设计

#### 温暖的语气

```
欢迎语:
"你好，欢迎来到解忧杂货铺。

在这里，你可以倾诉任何心事，分享任何感受。
无论是快乐还是忧愁，我都会用心倾听，陪你一起面对。"

空状态:
"在这里，每一份烦恼都会被温柔对待"

输入提示:
"说说你的心事..."
```

**特点**:
- 第二人称亲切称呼
- 温暖包容的态度
- 陪伴而非说教
- 给予心理安全感

#### 错误提示

```
连接失败:
"抱歉，暂时无法连接到服务。请稍后再试。"

消息发送失败:
"抱歉，我遇到了一些问题。请稍后再试。"

加载超时:
"抱歉，我现在有些困惑，能再说一遍吗？"
```

**特点**:
- 承认错误
- 不推卸责任
- 给予解决方案
- 保持温和语气
