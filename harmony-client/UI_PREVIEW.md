## 细节设计亮点

### 1. 灯笼图标 🏮
- **位置**: 助手消息左侧
- **大小**: 32pt
- **含义**: 象征温暖的指引和陪伴
- **视觉效果**: 醒目但不突兀

### 2. 圆角设计
```
大圆角 (20pt):
  └─ 消息气泡

中圆角 (12pt):
  └─ 输入框

完全圆角 (50%):
  └─ 发送按钮
```

### 3. 间距系统（8pt栅格）
```
4pt  - 极小间距
8pt  - 小间距
12pt - 标准间距
16pt - 大间距（页面边距）
20pt - 特大间距
32pt - 空状态留白
```

### 4. 文字层级
```
28pt / Semi-bold  - 空状态标题
20pt / Semi-bold  - 页面标题
16pt / Regular    - 正文
15pt / Regular    - 空状态副标题
14pt / Regular    - 辅助文字
13pt / Regular    - 页面副标题
```
